# ADR-001: Technology Stack (Next.js + Express + Supabase/Postgres)

## Context
Need a full-stack web app with rapid UI iteration and simple JSON APIs for academic demo scope.

## Decision
Use Next.js (app router) for the frontend; Express for REST APIs; Supabase/Postgres for relational persistence.

## Alternatives
- Next.js + Prisma + Postgres
- React (Vite) SPA + Fastify + Postgres
- Express + server-rendered templates (no Next.js)

## Rationale
Need rapid full-stack iteration, simple JSON contracts, and relational integrity for the academic data model. The stack minimizes boilerplate while matching existing code.

## Consequences
- Pros: Fast iteration, strong ecosystem, simple JSON contract.
- Cons: Requires schema migrations and more explicit query mapping than a document store.
